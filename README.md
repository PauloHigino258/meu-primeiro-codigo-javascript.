# ⚔️ Simulador de Status de Herói (RPG)

Este é um projeto inicial e super simples desenvolvido em JavaScript para praticar os conceitos fundamentais da programação. O script simula a ficha de um personagem de RPG e gerencia a alteração dos seus pontos de vida durante um combate.

## 🚀 Tecnologias Utilizadas

- **JavaScript** (ES6+)
- **Node.js** (para execução no terminal)

## 🧠 Conceitos Praticados

- **Variáveis**: Armazenamento de dados do personagem (`let`).
- **Funções**: Blocos de código reutilizáveis (`function`).
- **Estruturas Condicionais**: Uso de `if`/`else` para verificar a saúde do herói.
- **Operadores Aritméticos**: Decremento de pontos de vida (`-=`).
- **Manipulação do Console**: Exibição de dados com `console.log`.

## 📦 Como Executar o Projeto

1. Certifique-se de ter o **Node.js** instalado.
2. Clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
node nome_do_arquivo.js
```
